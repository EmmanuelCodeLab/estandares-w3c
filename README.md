# EcoTienda – Proyecto de auditoría W3C

Sitio académico de tres páginas: Inicio, Productos y Contacto.

## Ejecutar
Abre `index.html` en un navegador. No requiere instalación ni servidor.

## Publicar en GitHub Pages
1. Crea un repositorio público llamado `estandares-w3c`.
2. Sube todos los archivos y carpetas conservando la estructura.
3. En Settings > Pages, selecciona Deploy from a branch, rama `main` y carpeta `/ (root)`.
4. Guarda y espera la URL publicada.

## Validación
Pasa cada página por Nu HTML Checker, CSS Validation Service, WAVE y Lighthouse. Registra los resultados reales y adjunta capturas. No se han inventado puntuaciones ni resultados de herramientas en este paquete.

## Nota
El formulario es demostrativo: valida en el navegador y muestra un mensaje, pero no transmite información a un servidor.
